# Source quality and licensing

| Tier | Default source class |
| --- | --- |
| A | Primary government/statistical sources |
| B | Regulatory filings and corporate disclosures |
| C | International institutions and recognized research organizations |
| D | Industry data providers |
| E | Academic research |
| F | High-quality journalism |
| G | Alternative/open-source intelligence |
| H | Unverified claims |

Tier determines verification effort, **not truth**. Government measurements can
be revised; research can be wrong; a lower-tier claim can be correct. Evaluate
methodology, transparency, incentives, independence, revision history, and fit for
the specific claim.

Source registry records must include publisher, methodology, update cadence,
revision policy, licensing/redistribution permissions, and limitations. Public
access is not a redistribution license. Do not commit paid/restricted datasets.
The example data is invented and freely redistributable; it is not assigned
government-source credibility merely because its schema resembles a statistical release.
