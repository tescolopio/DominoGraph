# Hypothesis testing

Hypotheses are separate from observations. Record the claim, supporting evidence,
contradicting evidence, required datasets, falsification criteria, confidence,
status, related nodes, policies, and institutional statements.

Before evaluation:

1. State a testable claim and its scope/time horizon.
2. Identify observable predictions and alternative explanations.
3. Specify disconfirming observations and required datasets before searching.
4. Search for both support and contradictions; record remaining gaps.
5. Review source independence, revisions, measurement errors, and confounders.
6. Preserve the evaluation version and human review disposition.

An adversarial reviewer should try to disprove active hypotheses. The pilot defines
the provider interface and review states; periodic automated runs are not yet
scheduled. No contradiction found is not equivalent to no contradiction possible.
Synthetic hypotheses illustrate structure only and are not empirical conclusions.
