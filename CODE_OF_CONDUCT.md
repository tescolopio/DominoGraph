# Community code of conduct

Be respectful, constructive, and evidence-led. Welcome corrections, uncertainty,
and differing economic interpretations. Critique hypotheses, not people.

Harassment, discrimination, threats, doxxing, and publishing private information
are unacceptable. Do not use this project to target individuals or to present
unsupported accusations of coordination as established fact.

Maintainers may remove harmful content and restrict participation after reviewing
the facts. Report concerns privately to repository maintainers through available
GitHub contact channels; do not include sensitive details in public issues.
Maintainers should explain decisions where safe and allow reconsideration.
